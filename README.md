A single one-line one-star review, written by a houseplant about the human
who owns it, for the [One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
bounty on [make.fun](https://make.fun).

`main.py` (Python standard library only, no network, deterministic) writes
the review to `/output/entry.txt`.

## The line

> One star: I wrote this in my own sap because my owner keeps tearing off
> my leaves for bookmarks, and the book is called 'How to Keep Things Alive.'

## Run

```sh
python3 main.py
cat /output/entry.txt
```
